## 5. 傷害數字（10-D03）

| 種類 | 樣式 | 動態 |
|---|---|---|
| 自己或隊友打怪物 | 白色 | 從頭上彈起，再落下淡出（約 1 秒，RO 的感覺） |
| 自己受到傷害 | 紅色 | 同上 |
| 暴擊 | 黃色、放大 1.5 倍，背後有爆炸形的圖案 | 彈得比較高 |
| Miss | 「未命中」（英文版 Miss），淡灰色 | 往上飄、淡出；目標沒有動作（00-S10） |
| Lucky（完全迴避） | 「完全迴避」（英文版 Lucky） | 同 Miss |
| 二連擊 | 兩個白色數字依序出現，間隔 0.15 秒，左右稍微錯開 | 同一般 |
| 二連擊暴擊 | 兩個黃色暴擊數字依序出現，間隔 0.15 秒（06-D07） | 同暴擊 |
| 治癒 | 綠色數字 | 往上飄 |
| SP 回復（道具、技能） | 藍色數字 | 往上飄 |

- 數字在伺服器的命中時間出現（02 第 8 節、06 第 14 節），跟動作的命中點同一刻（05 第 9 節）。
- 數字的字型用 Noto Sans TC 粗體加深色描邊；同一個目標短時間內很多數字時，位置自動錯開，不會疊在一起。
- 物件池先放 64 個，不夠時自動加。
- 別人互打的數字顯示與否可以在設定裡切換（預設顯示）。

## 6. 特效（10-D06）

### 6.1 做法

| 種類 | 工具 |
|---|---|
| 火花、光點、煙、魔力粒子 | GPUParticles3D |

- 特效在事件的時間點播放（命中時間、施放時間、05 的動作標記）。

## 7. 字型、縮放與文字（10-D07、10-D08）

| 項目 | 內容 |
|---|---|
| 字型 | 繁中和英文用 Noto Sans TC（一般、粗體）；從 Google Fonts 取得，登記在授權表（`OFL-1.1`）。之後的語言照 `locales.json` 指定，切換時才載入 |
| 數字 | Noto Sans TC 粗體＋描邊 |
| 字型大小 | 1080p、縮放 1.0 時，內文 16 px、標題 20 px |
| 介面縮放 | 0.8～1.5，存在 `settings.cfg` 的 ui 區段（03 第 9.2 節） |
| 文字 | 一律用文字鍵（例如 `ui.hud.hp`），依目前的語言從 `locale/<語系>/` 取（03 第 7 節） |
| 語言切換 | 設定裡選（M1），存在 `settings.cfg` 的 `[ui] language`；切換後介面立刻更新，訊息欄的舊訊息也用新語言重新顯示（訊息存的是 ID 和參數） |
| 用語 | 照 `docs/glossary.md`：職業、技能、素質優先用台灣版 RO 的官方譯名；繁中只允許 HP、SP 兩個英文縮寫；全形標點、半形數字 |
| 自動截圖 | `--lang=en` 可以指定語言，同一組觀測點各截一次中英文；另外用 Godot 的偽本地化跑一次，找出寫死在程式或場景裡的文字、看英文變長時版面會不會爆掉 |

- Godot 用動態字型渲染中文，不需要事先產生字元表；第一次顯示某個字時會有一點點成本，M1 量測。

## 10. 聲音（10-D10）

### 10.1 匯流排

| 匯流排 | 用途 |
|---|---|
| Master | 主音量 |
| Music | 背景音樂 |
| SFX | 戰鬥、技能、腳步、怪物 |
| UI | 介面 |
| Ambience | 環境音（海浪、河、風、人聲、營火、鳥） |

- 音量存在 `settings.cfg` 的 audio 區段（03 第 9.2 節），設定視窗可以調。

### 10.2 背景音樂和環境音（M2-e）

| 項目 | 做法 |
|---|---|
| 背景音樂 | 每張地圖一首，寫在地圖的 `map.tscn`（客戶端）；伺服器不讀（01-D07）。檔案已經由管線做好循環點（04 第 8.4 節） |
| 換圖 | 音樂淡出、淡入約 1 秒；兩張地圖用同一首時就繼續播 |
| 環境音 | 地圖的發聲點（08 第 7.5 節）：AudioStreamPlayer3D，音量隨距離衰減，範圍外淡出 |
| 標題、選角 | 之後（M8～M9） |

### 10.3 音效

| 類別 | 什麼時候播 | 里程碑 |
|---|---|---|
| 腳步 | 動作的 `footstep_l`、`footstep_r` 標記（05-D10）；依腳下的地面種類換：石板、草地、沙、木板（碼頭、棧橋）、泥土。地面種類看 Terrain3D 的地形材質，建築和橋看碰撞形狀的 `surface` 標記 | M3-c |
| 怪物 | 攻擊（命中時間）、受擊、死亡、移動（07 第 7.4 節）；檢視器也聽得到 | M4 |
| 打擊 | 揮擊（6 種武器）、命中（依目標：肉、木頭、果凍）、暴擊、升級 | M5 |
| 技能 | 詠唱、施放、命中 | M7 |
| 介面 | 點擊、開關視窗、錯誤、撿取、裝備 | M8 |

- 音效在事件的時間點播放（命中時間、施放時間、動作標記），跟特效同一刻。
- 3D 定位的音效是單聲道（04 第 8.4 節），用物件池。
- 第一版的聲音清單和來源在 04 第 13.7 節。

## 13. 風險與備案

| 風險 | 影響 | 備案 |
|---|---|---|
| 中文字型檔很大、第一次顯示某個字時卡一下 | 打開視窗時頓一下 | 啟動時先預熱常用字；必要時把字型縮減成常用字 |
| 特效太多掉幀 | 效能 | F3 面板監看粒子數；設定裡提供特效品質 |
| FF14 的質感和 RO 的資訊放在一起不協調 | 看起來不統一 | M5 截圖後跟你一起調；版面元件都可以換樣式 |
| 英文比中文長，版面爆掉 | 英文介面難看 | 偽本地化的自動截圖（第 12 節第 9 項）；元件用自動換行和最小寬度 |
| 音樂、環境音太吵或太單調 | 聽久了煩 | 匯流排的音量可以調；環境音和音樂的音量在 M2-e 一起試 |

## 14. 與 RO 原制不同之處（待檢視）

| 項目 | RO 原制 | 本專案 | 理由 |
|---|---|---|---|
| HUD 的版面 | RO 的基本資料視窗、快捷列 | FF14 式的版面，資訊照 RO | 00-S08 |
| 怪物的 HP 條 | 一般怪物不顯示（只有 MVP 等特殊情況） | 選為目標或受傷後 10 秒內顯示 | 方便判斷戰況；可以在設定裡關掉 |
| 表情 | 只有頭上的表情圖示 | 圖示加上全身的表情動作 | 00-A08 |
| 特效的造型 | RO 的特效 | 原創造型，時機照 RO | 00-A02 |
| 附加能力的名稱顏色 | 沒有 | 依條數：0 白、1 綠、2 藍、3 紫 | 你的指示（2026-10-11） |
| 怪物的「?」「!」圖示 | 沒有 | 警戒時「?」、開始追擊時「!」 | 讓玩家知道被發現了（07 的感知） |
| 任務追蹤列 | 只有任務視窗 | 畫面右側另外顯示進行中的任務（可以關掉） | 參考 FF14（00-S08） |
| 地圖的環境音 | 有，但不多 | 每張地圖都放（08 第 7.5 節） | 寫實 3D 需要（00-A03） |
| 中文版的戰鬥文字 | Miss、Lucky 的圖案文字 | 「未命中」「完全迴避」 | 不中英混合（00-S06）；英文版照 RO |

除了上表，本文件其他部分都照 RO：
- 傷害數字的顏色和種類（白、紅、綠、Miss、Lucky、暴擊、二連擊）
- 視窗的按鍵 Alt＋A、E、Q、S
- 怪物名稱在滑鼠停留時顯示
- 死亡時「回到儲存點」
- 每張地圖一首背景音樂；怪物、打擊、技能、介面都有音效
- 任務視窗的按鍵 Alt＋U；換圖的載入畫面有插圖
