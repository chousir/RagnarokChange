│ └──────────────────────┘                                  地圖名稱    │
│  [狀態圖示＋剩餘時間]                                                  │
│                                                                      │
│                            （遊戲畫面）                               │
│                                                                      │
│                        ┌───────── 詠唱條 ─────────┐                   │
│ ┌──────────────┐       └──────────────────────────┘                   │
│ │ 訊息欄        │   [F1][F2][F3][F4][F5][F6][F7][F8][F9]  技能列        │
│ │（系統、戰鬥）  │   Base ▓▓▓▓▓▓▓▓░░░░ 62.4%                             │

| 元件 | 內容 | 第一版 |
|---|---|---|
| 角色框 | 名稱、Base 和 Job 等級、HP、SP（數字和條） | M5（M1 先有名稱） |
| 目標框 | 目標名稱、等級、HP 百分比 | M5 |
| 狀態圖示 | 圖示和剩餘時間，滑鼠停留顯示說明 | M7 |
| 詠唱條 | 技能名稱、進度；被打中斷時閃紅 | M7 |
| 技能列 | F1～F9，可以把技能拖上去；顯示冷卻和技能後延遲 | M7 |
| 經驗條 | Base 和 Job 經驗的百分比 | M5 |
| 訊息欄 | 系統訊息、戰鬥訊息（獲得經驗、物品）；之後加上聊天 | M1 |

- 版面的質感（半透明的深色底、細邊框、乾淨的字）參考 FF14，但資訊和按鍵照 RO。
- 小地圖用編輯器工具從地圖上方正交渲染一張圖，存在地圖資料夾裡（不在執行時渲染）。

## 4. 名牌、目標、游標、圖示（10-D04、10-D05）

| 項目 | 內容 |
|---|---|
| 玩家名牌 | 頭上顯示名稱，一直顯示；距離 40 m 以外淡出 |
| 怪物名牌 | 滑鼠停留或選為目標時顯示名稱（照 RO） |
| 怪物 HP 條 | 選為目標時，或受到傷害後 10 秒內，在怪物腳下顯示 |
| 目標標記 | 被選的目標腳下有圈，攻擊中的目標圈變紅 |
| 描邊 | 滑鼠停留的對象描邊（09 第 5.1 節） |
| 游標 | 一般、攻擊（劍）、撿取（手）、對話（之後）、技能選目標（準星）、地面技能（圓圈） |
| 表情圖示 | 做表情時頭上冒出原創的表情圖示，約 2 秒（RO 的表情也是頭上的圖示） |

- 名牌、HP 條是畫面空間的 UI 元件，位置跟著實體頭頂；用物件池。

## 5. 傷害數字（10-D03）

| 種類 | 樣式 | 動態 |
|---|---|---|
| 自己或隊友打怪物 | 白色 | 從頭上彈起，再落下淡出（約 1 秒，RO 的感覺） |
| 自己受到傷害 | 紅色 | 同上 |
| 暴擊 | 黃色、放大 1.5 倍，背後有爆炸形的圖案 | 彈得比較高 |
| Miss | 「Miss」文字，淡灰色 | 往上飄、淡出；目標沒有動作（00-S10） |
| Lucky（完全迴避） | 「Lucky」文字 | 同 Miss |
| 二連擊 | 兩個白色數字依序出現，間隔 0.15 秒，左右稍微錯開 | 同一般 |
| 治癒 | 綠色數字 | 往上飄 |
| SP 回復（道具、技能） | 藍色數字 | 往上飄 |

- 數字在伺服器的命中時間出現（02 第 8 節、06 第 14 節），跟動作的命中點同一刻（05 第 9 節）。
- 數字的字型用 Noto Sans TC 粗體加深色描邊；同一個目標短時間內很多數字時，位置自動錯開，不會疊在一起。
- 物件池先放 64 個，不夠時自動加。
- 別人互打的數字顯示與否可以在設定裡切換（預設顯示）。

## 6. 特效（10-D06）

### 6.1 做法

| 種類 | 工具 |
|---|---|
| 火花、光點、煙、魔力粒子 | GPUParticles3D |
| 詠唱魔法陣、技能範圍、目標圈 | Decal（投影在地面上） |
| 光柱、護盾、溶解（死亡淡出）、水面 | 著色器 |
| 武器揮動的軌跡 | 拖尾網格（起點和終點在武器的外觀設定，05 第 4.2 節） |
| 噴水池的水流 | 粒子＋網格動畫 |

- 特效場景放在 `assets/vfx/<visual_id>/`（03 第 5 節），由資料的 `visual_id` 指到。
- 特效在事件的時間點播放（命中時間、施放時間、05 的動作標記）。

### 6.2 第一版的特效

| 特效 | 時機 | 里程碑 |
|---|---|---|
| 命中火花（斬擊、穿刺、鈍擊、拳頭四種） | 命中時間 | M5 |
| 暴擊的爆發 | 命中時間 | M5 |
| 升級（Base、Job） | 升級的那一刻 | M5 |
| 死亡淡出 | 死亡動作播完 | M5 |
| 傳送門（傳送點的光） | 一直顯示 | M1 |
| 出現（新出現、重生） | 出現時 | M6 |
| 掉落物的閃光 | 掉落時、在地上時 | M6 |
| 詠唱魔法陣 | 詠唱期間 | M7 |
| 第一版技能的特效（狂擊、怒爆、挑釁、霸體、治癒術、加速術、緩速術、天使之賜福、天使之障壁、隱匿、施毒、解毒、光獵、光之障壁、瞬間移動、十字驅魔、治療） | 施放、命中 | M7 |
| 狀態效果的特效（中毒、加速等） | 狀態期間 | M7 |

- 造型全部原創，但特效出現的時機和意義照 RO（例如詠唱期間腳下有魔法陣、升級時有光柱）。
- 每種特效的粒子數量要在效能預算內；F3 面板顯示目前的粒子數。

## 7. 字型、縮放與文字（10-D07、10-D08）

| 項目 | 內容 |
|---|---|
| 字型 | Noto Sans TC（一般、粗體）；從 Google Fonts 取得，登記在授權表（`OFL-1.1`） |
| 數字 | Noto Sans TC 粗體＋描邊 |
| 字型大小 | 1080p、縮放 1.0 時，內文 16 px、標題 20 px |
| 介面縮放 | 0.8～1.5，存在 `settings.cfg` 的 ui 區段（03 第 9.2 節） |
| 文字 | 一律用文字鍵（例如 `ui.hud.hp`），中文從 `locale/zh_TW/` 取（03 第 7 節） |

- Godot 用動態字型渲染中文，不需要事先產生字元表；第一次顯示某個字時會有一點點成本，M1 量測。

## 12. 測試與驗收方式

**M1：**
1. 換圖時畫面淡出、顯示地圖名稱，MapReady 之後才淡入，看不到東西一個一個冒出來。
2. F3 面板的數字跟 Godot 內建的效能監視一致。
3. 介面縮放 0.8、1.0、1.5 三種截圖，版面不會重疊或超出畫面（我先看，再請你確認）。

**M5：**
4. 傷害數字在命中時間出現（誤差 ≤ 1/60 秒）；一般、暴擊、Miss、Lucky、二連擊、治癒的樣式都對。
5. 一秒內打出 20 個數字，數字不會疊在一起，物件池沒有一直新增節點。
6. 截圖清單（給你看）：各種傷害數字、暴擊特效、升級特效、死亡畫面。

**M7：**
7. 每個第一版技能的特效都在正確的時間播放；詠唱被打斷時魔法陣消失、詠唱條閃紅。

## 13. 風險與備案

| 風險 | 影響 | 備案 |
|---|---|---|
| 中文字型檔很大、第一次顯示某個字時卡一下 | 打開視窗時頓一下 | 啟動時先預熱常用字；必要時把字型縮減成常用字 |
| 特效太多掉幀 | 效能 | F3 面板監看粒子數；設定裡提供特效品質 |
| FF14 的質感和 RO 的資訊放在一起不協調 | 看起來不統一 | M5 截圖後跟你一起調；版面元件都可以換樣式 |

## 14. 與 RO 原制不同之處（待檢視）

| 項目 | RO 原制 | 本專案 | 理由 |
|---|---|---|---|
| HUD 的版面 | RO 的基本資料視窗、快捷列 | FF14 式的版面，資訊照 RO | 00-S08 |
| 怪物的 HP 條 | 一般怪物不顯示（只有 MVP 等特殊情況） | 選為目標或受傷後 10 秒內顯示 | 方便判斷戰況；可以在設定裡關掉 |
| 表情 | 只有頭上的表情圖示 | 圖示加上全身的表情動作 | 00-A08 |
| 特效的造型 | RO 的特效 | 原創造型，時機照 RO | 00-A02 |

除了上表，本文件其他部分都照 RO：
- 傷害數字的顏色和種類（白、紅、綠、Miss、Lucky、暴擊、二連擊）
- 視窗的按鍵 Alt＋A、E、Q、S
- 怪物名稱在滑鼠停留時顯示
- 死亡時「回到儲存點」
