## 3. 鏡頭（09-D01、09-D02）

### 3.1 操作

| 操作 | 效果 |
|---|---|
| 按住左鍵拖曳 | 只轉鏡頭（角色不轉） |
| 按住右鍵拖曳 | 轉鏡頭，角色的面向跟著鏡頭 |
| 左右鍵同時按住 | 往前走（FF14 的習慣） |
| 滾輪 | 平滑縮放 |
| Home | 鏡頭回到角色背後 |
| 拖曳時 | 隱藏游標，放開後游標回到原本的位置 |

- 單純點一下左鍵（沒有拖曳）才算點選；拖曳超過 4 像素就算轉鏡頭。

### 3.2 參數

| 參數 | 預設 | 範圍或說明 |
|---|---|---|
| 距離 | 6 m | 1.5～20 m |
| 縮放 | 每格滾輪 ×0.85 或 ×1.18，0.15 秒內平滑到位 | 設定可調 |
| 俯仰角 | −20° | −70°（往下看）～＋30°（往上看） |
| 注視點 | 角色腳底往上 1.5 m | 拉近到 2 m 以內時降到 1.4 m |
| 視角 | 垂直 60° | 設定可調 55°～75° |
| 靈敏度 | 每像素 0.25° | 設定可調、可以反轉 Y 軸 |
| 跟隨 | 位置立即跟隨，旋轉平滑 | — |

### 3.3 碰牆

```text
注視點 ──────────────球形投射（半徑 0.2 m）─────────────► 想要的鏡頭位置
             撞到牆 → 鏡頭立刻移到撞到的位置前面
             離開牆 → 0.3 秒內慢慢回到想要的距離
```

- 投射只碰客戶端的「鏡頭碰撞」層（08 的 Collision）：建築、城牆、岩石、樹幹；不碰角色、怪物、草和小道具。
- 拉近到 1 m 以內時，角色的模型淡出，避免鏡頭穿進角色裡。

## 4. 移動（09-D03、09-D04）

| 項目 | 內容 |
|---|---|
| 方向 | W 前、S 後、A 左、D 右，以鏡頭的水平方向為準；斜向移動速度不會變快 |
| 面向 | 角色轉向移動的方向（平滑轉向）；按住右鍵時面向鏡頭的方向 |
| 速度 | 照伺服器（06）：正常是 6.67 m/s（`player_move_speed_mps`；RO 是 150 毫秒一格），狀態會改變速度 |
| 動作 | 正常速度播跑步；被減速、或開了走路切換時播走路（05-D17） |
| 走路切換 | 按 `/` 切換；走路時移動速度是 1/2，噪音降到 20%（07 第 5.5 節）；HUD 顯示「走路中」的小圖示（10） |
| 跳躍 | 沒有（RO 沒有，01-D08） |
| 不能移動時 | 坐下、詠唱、攻擊動作中、受擊硬直、死亡（06）；按移動鍵會先取消可以取消的事（例如自動追擊），但不會打斷詠唱 |

- 移動輸入就是 02 第 7.1 節的 MoveInput：每 33 毫秒送一次方向、面向和旗標（走路切換是旗標之一）。

## 5. 目標與攻擊（09-D05、09-D06、09-D11）

### 5.1 選目標

| 操作 | 效果 |
|---|---|
| 左鍵點怪物 | 選取並開始攻擊（自動追擊＋連續普攻） |
| 左鍵點玩家 | 選取（不攻擊） |
| 左鍵點 NPC | 走到 2 m 內，打開對話（M8，第 5.4 節） |
| Tab | 選畫面前方 30 m 內最近的可以攻擊的怪物；再按一次換下一隻 |
| Shift＋Tab | 反方向輪流 |
| R（攻擊鍵） | 對已選的目標開始攻擊 |
| Esc、點地面 | 取消目標（也停止攻擊） |

- 「畫面前方」是鏡頭方向左右 60° 以內；選的順序依距離。
- 滑鼠停在可以點的對象上時，對象會描邊，游標也會改變（樣式在 10）。

### 5.2 自動追擊和攻擊

```text
開始攻擊（點怪或按 R）
  → 目標在射程外：用導航網格算路，轉成一般的移動輸入（02 第 10 節）
       每 0.25 秒，或目標移動超過 1 m 時，重新算路
  → 走到「射程 − 0.2 m」以內：停下、面向目標、送出 AttackStart（連續）
  → 伺服器依 ASPD 揮擊（06）；目標跑遠時收到 AttackOutOfRange，繼續追
  → 結束：按任何移動鍵、Esc、點地面、目標死亡或消失、找不到路
```

- 單次攻擊（RO 不按 Ctrl 時的行為）在協定裡保留（02），第一版的操作上不提供；之後如果要，可以加一個「單次攻擊」的按鍵。

### 5.3 撿東西（09-D08）

| 操作 | 效果 |
|---|---|
| 左鍵點地上的物品 | 走到 1.5 m 內撿（06 第 13.1 節） |
| F（撿取鍵） | 撿 5 m 內最近的物品（走過去撿） |

### 5.4 點 NPC（09-D13，M8）

```text
左鍵點 NPC
  → 選取 NPC（描邊、目標框顯示名字）
  → 距離 > 2 m：用導航網格走過去（跟自動追擊一樣）
  → 2 m 以內：停下、面向 NPC、送出 NpcInteract（02）
  → 伺服器送出對話節點 → 打開對話視窗（10）
  → 結束：選了結束的選項、Esc、走開超過對話距離
```

- 走過去的途中按移動鍵就取消。
- 對話中可以轉鏡頭；移動就關閉對話（跟 RO 一樣，對話時不能做其他事）。

## 6. 技能與其他操作（09-D07、09-D08）

### 6.3 改鍵（09-D09）

- 所有動作都定義在 InputMap，名稱用英文（例如 `move_forward`、`skill_bar_1`、`sit`）。
- 改鍵畫面在 10；設定存成純文字（例如 `"Alt+A"`），只存跟預設不同的部分（03 第 9.2 節）。
- 改鍵時檢查衝突：同一個按鍵不能綁兩個會同時生效的動作。

## 7. 滑鼠點選（09-D10）

- 每個實體有一個點選用的簡單碰撞形狀（膠囊或方塊，04 第 11 節的匯入腳本自動加上），放在客戶端專用的「點選」碰撞層；伺服器沒有這些碰撞。
- 點擊時從鏡頭經過游標發出射線，依序檢查：怪物 → NPC → 地上的物品 → 玩家 → 地面。
- 碰撞形狀的半徑是資料的 `body_radius_m`＋0.15 m（怪物、NPC，03 第 4.5、4.17 節；玩家用 `player_body_radius_m`），高度是 `height_m`；比模型稍大一點，小怪物也好點。
- 每幀做一次滑鼠停留的偵測，用來描邊和改變游標。

## 9. 測試與驗收方式

**M1：**
1. 鏡頭：左鍵拖曳只轉鏡頭；右鍵拖曳時角色跟著轉；滾輪縮放在 1.5～20 m 之間；俯仰角不會超出限制。
2. 碰牆：靠著城牆轉鏡頭，鏡頭不會穿進牆裡；離開後平順地回到原本的距離（自動截圖、我先看）。
3. 移動：WASD 的方向以鏡頭為準；斜向速度跟直線一樣；走路切換後速度是 1/2，動作變成走路。
4. 按鍵設定：改了一個鍵、重開遊戲後還在；設定檔只多一行。

**M5：**
5. 點怪 → 自動追擊 → 進入射程開始攻擊；按 W 立刻停止追擊和攻擊（02 第 16 節 M5 的整合測試）。
6. Tab：依距離輪流選前方的怪物；Esc 取消。
7. 點選的優先順序：怪物和玩家重疊時選到怪物。

**2026-10-11 加的（編號接在後面）：**
8. 點選的範圍（M5）：怪物的碰撞半徑是 `body_radius_m`＋0.15 m；點在範圍邊緣也選得到。
9. 點 NPC（M8）：太遠時自動走過去，2 m 內打開對話；走過去的途中按移動鍵就取消；移動就關閉對話。

**給你看的截圖清單（M1）：** 鏡頭最近、最遠、最低、最高的四張；城牆邊轉鏡頭的連續截圖。

## 10. 風險與備案

| 風險 | 影響 | 備案 |
|---|---|---|
| 鏡頭在狹窄的巷子裡一直撞牆 | 畫面晃動 | 投射半徑和回復速度可以調；必要時對小巷加上專用的鏡頭碰撞形狀 |
| 自動追擊時一直重新算路 | 客戶端 CPU 負擔 | 重新算路有時間和距離門檻（0.25 秒、1 m） |
| F1～F9 不好按 | 操作不順 | 改鍵；或改成 1～0 的方案（待檢視） |
| 拖曳和點選的判斷錯誤 | 想轉鏡頭卻選到東西 | 4 像素的門檻可以調 |

## 11. 與 RO 原制不同之處（待檢視）

| 項目 | RO 原制 | 本專案 | 理由 |
|---|---|---|---|
| 移動 | 點地面移動 | WASD（以鏡頭方向為準） | 00-S02 決定的 |
| 鏡頭 | 固定的斜上方視角，可以旋轉和縮放一點點 | FF14 式自由鏡頭 | 00-A05 決定的 |
| 走路切換 | 沒有（只有一種移動速度） | 有，速度 1/2，噪音降到 20%（怪物比較聽不到） | 寫實 3D 需要能慢慢走；噪音是你的指示（2026-10-11），怪物的感知在 07 |
| 選目標 | 只能用滑鼠點 | 另外有 Tab 輪流選、攻擊鍵 R | 00-S02、計畫大綱 |
| 撿東西 | 只能用滑鼠點 | 另外有撿取鍵 F | 計畫大綱 |
| 連續攻擊 | 預設點一下打一下，按 Ctrl 或 /noctrl 才連續 | 預設連續 | 00-S02 決定的 |
| 取消攻擊 | 點地面 | 按任何移動鍵（也可以點地面） | WASD 的對應做法 |

除了上表，本文件其他部分都照 RO：
- 技能列 F1～F9、坐下 Insert、表情 Alt＋數字、視窗 Alt＋A、E、Q、S、截圖 Print Screen
- 攻擊時站著不動、目標在射程外時自動走過去
- 沒有跳躍
