## 4. 3D 模型：拿掉 Tripo，改用 Colab 的 Hunyuan3D-2

使用者的工具：https://github.com/chousir/colab-ImageTo3D（`hunyuan3d2_colab_t4.ipynb`）。正面圖 → MV-Adapter 自動產生左、後、右視角 → Hunyuan3D-2mv 產生形狀 → Hunyuan3D-2 產生貼圖 → GLB。

| 項目 | 決定 |
|---|---|
| 主要工具 | Colab 的 Hunyuan3D-2。Tripo 從主要流程拿掉，只留在 04 白名單當備案（要用時用付費方案） |
| 使用者要做的 | 只要給**正面圖**（檔名 `<類別>-<id>-front.png`，Colab 的規則）；左、後、右由 Colab 產生。美術指南的「生成四視角」改成「自動視角不好時才用 P-02～P-04 補」 |
| 投遞 | Colab 的輸出 `hunyuan3d2-<類別>-<id>.glb` 和 `.json` 放 `assets/_inbox/`；04-D06 的來源加 `hunyuan3d2`。檔名本來就符合 `<來源>-<類別>-<名稱>` |
| 角色的分件 | Hunyuan3D 不會分件：管線在脖子切掉頭，換成共用頭部（04-D11）；頭髮用 MPFB2 的髮型，或用髮型的正面圖另外生成 |
| 貼圖 | 只有顏色貼圖；法線、粗糙度、金屬度由管線依類別補預設值（之後可以在 Blender 烘焙法線） |
| 面數 | 照 Colab 的 `PRESETS` 先減面，管線再照 04 第 12 節的預算處理 |
| 授權 | `LicenseRef-Tencent-Hunyuan3D-2-Community`。騰訊不主張產出的權利；不能用產出改進其他 AI 模型；條款不適用於歐盟、英國、韓國（登記限制 `territory_excludes_eu_uk_kr`）；月活躍使用者超過 100 萬要另外申請。產生視角用的 MV-Adapter 是 Apache-2.0，底層的 SDXL 是 CreativeML Open RAIL++-M。登記時記下 Colab 的種子和模型版本（輸出的 `.json`） |
| 小樹精的備案 | 原本的備案是 Tripo 的多腳自動綁骨，改成「自建骨架」唯一做法 |
| 要改的文件 | 04（第 5 節白名單、04-D04、04-D12、第 6.2 節、第 7 節、第 14 節、第 17 節等所有寫到 Tripo 的地方）；11（各批次「在 Tripo 生成」改成「用 Colab 生成」）；`art-asset-guide`（第 5 節的 Tripo 設定、第 6 節的「設定組」、第 9 節交件清單的「Tripo 模型」欄）；`art-prompts`（P-01～P-04 改成「補視角用」） |
